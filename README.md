## О проекте

Этот репозиторий содержит материалы магистерского исследования, посвящённого проблеме перевода **лингвокультурем** — культурно-маркированных языковых единиц, которые не имеют прямых эквивалентов в других языках и создают наибольшие трудности при переводе.

Исследование продолжает выпускную квалификационную работу бакалавриата, в которой были систематизированы 180 лингвокультурем из романа Е. Водолазкина «Лавр» и проведён сопоставительный анализ профессионального, машинного и ИИ-перевода.

**Главный вопрос магистерского исследования:**  
Могут ли современные большие языковые модели (LLM) адекватно передавать культурно-маркированную лексику, и если нет — как это исправить?

## Научная новизна

Впервые проводится комплексный сопоставительный анализ перевода лингвокультурем романа Е. Водолазкина «Лавр» на немецкий язык с участием:

- профессионального переводчика (О. Радецкая)
- системы машинного перевода (Яндекс.Переводчик)
- большой языковой модели (ChatGPT)

На основе анализа разрабатывается **бенчмарк** — набор заданий с эталонными ответами для оценки качества перевода культурно-маркированной лексики.

## Основные результаты бакалаврского исследования

1. Систематизированы **180 лингвокультурем** из романа «Лавр»
2. Разработана **классификация** (явные, скрытые, этнографические, исторические, социальные, лексические)
3. Составлен **немецкий глоссарий** лингвокультурем
4. Проведён **сопоставительный анализ** трёх типов перевода
5. Выявлены **типичные ошибки** машинного и ИИ-перевода
6. Сделан вывод о необходимости **гибридного подхода**
