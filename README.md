# Бенчмарк для оценки перевода лингвокультурем

Бенчмарк — это набор заданий с эталонными ответами для проверки качества перевода, выполняемого языковыми моделями.

## Цель

Оценить, насколько хорошо современные LLM (ChatGPT, YandexGPT, GigaChat) справляются с переводом культурно-маркированной лексики.

## Структура

- `tasks.md` — задания: список лингвокультурем с контекстом
- `answers_human.md` — эталонные переводы, выполненные профессиональным переводчиком

## Методология

1. Отобраны 50 лингвокультурем из 180 (по 8–10 из каждой категории)
2. Для каждой указан контекст употребления в романе
3. Эталонный перевод — версия О. Радецкой
4. Каждой модели даётся одинаковый промпт
5. Результаты сравниваются с эталоном

## Критерии оценки

- **Точность** — совпадение с эталоном
- **Полнота** — сохранение культурного смысла
- **Адекватность** — понятность для носителя языка
