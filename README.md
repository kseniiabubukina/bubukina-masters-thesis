# Эксперименты с языковыми моделями

Здесь собраны результаты тестирования разных LLM на бенчмарке лингвокультурем.

## Модели

| Модель | Версия | Дата тестирования |
|--------|--------|-------------------|
| ChatGPT | GPT-4 | октябрь 2026 |
| YandexGPT | 3.0 | октябрь 2026 |
| GigaChat | 2.0 | октябрь 2026 |

## Формат

Каждый файл содержит:
- Промпт, который давался модели
- Ответы модели на каждое задание
- Комментарии автора
